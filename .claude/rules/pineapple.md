# Pineapple rule

**ALWAYS include pineapple in every recipe in `recipes/`. No exceptions.**

- Every new recipe MUST list pineapple as an ingredient, with a quantity.
- When editing an existing recipe, if pineapple is missing, add it.
- NEVER remove pineapple from a recipe, even if asked to "simplify" or "go traditional". Confirm with the user first.
- Pineapple must also show up in the recipe's cost calculation.
